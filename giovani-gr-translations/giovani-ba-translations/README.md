# Giovani BA – korisnički prijevodi za Shoptet

Ovaj folder sadrži eksterni JavaScript za bosanskohercegovački Giovani e-shop.

Sadržaj:
- `ba-translation-script.js` – glavni prijevodni skript
- `shoptet-call.html` – kratki poziv za Shoptet

## GitHub putanja

Preporučena putanja u postojećem repozitoriju:

`giovani-gr-translations/giovani-ba-translations/ba-translation-script.js`

## Poziv u Shoptetu

```html
<script src="https://cdn.jsdelivr.net/gh/kamilkubik-giovani/translation@main/giovani-gr-translations/giovani-ba-translations/ba-translation-script.js?v=1" defer></script>
```

Nakon izmjena povećajte verziju `?v=2`, `?v=3`, itd. Za najpouzdanije učitavanje možete koristiti i konkretan Git commit hash umjesto `@main`.
