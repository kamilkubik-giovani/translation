# Giovani PT - utilizadorské preklady pre Shoptet

Externý prekladový skript pre portugalský e-shop Giovani.

- `pt-translation-script.js` - hlavný skript (252 fráz)
- `shoptet-call.html` - volanie do Shoptetu

Skript sa spustí iba na doménach `giovani.pt` a `www.giovani.pt`.

Odporúčaná cesta v aktuálnom repozitári:

`giovani-gr-translations/giovani-pt-translations/pt-translation-script.js`

Po každej úprave zvýšte číslo verzie v odkaze, napríklad `?v=2`.
