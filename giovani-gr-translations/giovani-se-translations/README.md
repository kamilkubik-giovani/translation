# Giovani SE translations

Extern svensk översättningsskript för Shoptet på `giovani.se`.

## GitHub-sökväg

Ladda upp hela mappen till:

`giovani-gr-translations/giovani-se-translations/`

Slutlig JS-sökväg:

`giovani-gr-translations/giovani-se-translations/se-translation-script.js`

## Shoptet-anrop

```html
<script src="https://cdn.jsdelivr.net/gh/kamilkubik-giovani/translation@main/giovani-gr-translations/giovani-se-translations/se-translation-script.js?v=1" defer></script>
```

Efter ändringar rekommenderas att använda en specifik Git commit-hash i stället för `@main` för att undvika cacheproblem.
