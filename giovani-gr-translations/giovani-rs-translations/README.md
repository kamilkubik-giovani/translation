# Giovani RS – korisnički prevodi za Shoptet

Eksterni JavaScript za srpski e-shop Giovani.

## Sadržaj

- `rs-translation-script.js` – glavni prevodilački skript
- `shoptet-call.html` – poziv skripta za Shoptet

## GitHub putanja

Otpremite fasciklu ovde:

`giovani-gr-translations/giovani-rs-translations/`

## Poziv u Shoptetu

```html
<script src="https://cdn.jsdelivr.net/gh/kamilkubik-giovani/translation@main/giovani-gr-translations/giovani-rs-translations/rs-translation-script.js?v=1" defer></script>
```

Posle izmene povećajte verziju `v=2`, `v=3` itd. Za potpuno pouzdano učitavanje možete umesto `@main` koristiti hash konkretnog GitHub commita.
